======================================================================
ADVANCED HTML
======================================================================

DESCRIPTION
-----------
Ce projet a pour objectif de vous apprendre à structurer correctement une
page web en utilisant uniquement du HTML. Aucun CSS, aucun style visuel :
l’objectif est de maîtriser la structure, la sémantique et l’organisation
d’un document HTML5.

L’accent est mis sur :
    - la rigueur (minuscules, orthographe des balises, attributs),
    - la compréhension des balises HTML5,
    - la construction d’une page complète et valide W3C.

LEARNING OBJECTIVES
-------------------
À la fin de ce projet, vous devez être capable d’expliquer clairement :

Which guidelines to follow for HTML
    Respecter la syntaxe, la hiérarchie, la sémantique et les bonnes pratiques.

How to create the skeleton of an HTML5 page
    Construire une structure minimale : <!DOCTYPE html>, <html>, <head>, <body>.

How to use semantic HTML tags to structure a web page
    Utiliser header, main, footer, nav, section, article, aside.

Which use cases to use div vs span
    div : bloc structurel
    span : élément en ligne pour du texte ou des petites portions.

The semantic value of header, main, footer, article, nav, section, aside
    Comprendre leur rôle dans l’accessibilité et le SEO.

How to use headings (and why hierarchical order matters)
    Utiliser h1 → h6 dans un ordre logique pour structurer le contenu.

How to make lists in HTML
    ul, ol, li pour organiser des éléments.

The differences between medias (SVG, GIF, PNG, JPG)
    Comprendre les usages, avantages et limites de chaque format.

How to structure data in a table
    table, thead, tbody, tr, th, td.

How to integrate a video in a webpage
    <video> avec src, controls, autoplay, loop.

How to integrate an audio file in a webpage
    <audio> avec les mêmes principes que <video>.

How to embed external content
    <iframe> pour intégrer des contenus externes.

How to correctly structure an HTML page
    Construire une page cohérente, lisible, accessible et valide W3C.

OBJECTIF GLOBAL
---------------
Ce projet vous apprend à :
    - écrire du HTML propre, clair et sémantique,

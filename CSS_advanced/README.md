ADVANCED CSS
======================================================================

DESCRIPTION
-----------
Ce projet approfondit les bases du CSS et introduit des concepts avancés
permettant de structurer, organiser et styliser des pages web de manière
professionnelle.

L’objectif est de comprendre :
    - comment fonctionnent les sélecteurs,
    - comment gérer la spécificité,
    - comment utiliser des variables CSS,
    - comment manipuler des layouts (float grid),
    - comment animer et transformer des éléments,
    - comment assurer une compatibilité multi-navigateurs.

Aucun framework n’est utilisé : uniquement du CSS pur.

LEARNING OBJECTIVES
-------------------
À la fin de ce projet, vous devez être capable d’expliquer clairement :

Selectors, properties, and values
    Comprendre comment cibler un élément et lui appliquer un style.

The difference between block and inline styling
    Savoir comment les éléments se comportent dans le flux du document.

How to ensure consistency across all browsers (CSS reset)
    Utiliser un reset ou normalize pour uniformiser le rendu.

How to setup CSS variables
    Définir et utiliser des variables via :root et var().

The differences between inline, embedded and external CSS
    inline  : dans l’attribut style
    embedded: dans <style>
    external: dans un fichier .css

How grid systems work (with floats)
    Construire des layouts avant l’arrivée de CSS Grid/Flexbox.

The difference between icons webfonts and SVG icons
    webfonts : icônes via police (Font Awesome, etc.)
    SVG      : icônes vectorielles scalables et accessibles.

The difference between pseudo-classes and pseudo-elements
    pseudo-classes  : état (hover, active, focus…)
    pseudo-elements : partie d’un élément (::before, ::after…)

How to make background gradients
    Utiliser linear-gradient, radial-gradient.

How to animate elements in CSS
    keyframes, animation, transition.

How to transform (2d, 3d) elements
    transform: rotate, scale, translate, skew, perspective.

What vendor prefixes are
    Préfixes pour compatibilité navigateurs : -webkit-, -moz-, -o-, -ms-.
